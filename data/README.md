# Local drawings

Engineering drawings and uploads are not committed. Use **Open drawing** in the UI to upload your own PDF or image.

For the original 2401-specific integration tests and validation, place the original 12-page document at `data/2401.pdf`. Do not substitute a different drawing under this name: the 2401 profile contains document-specific legend and title-block rules.

Uploaded files are stored locally in `data/uploads/`, which is ignored by Git.
