How this preserves meaning

Observe the pattern

Group aligned stroke fragments, separate local gap patterns and keep the dash grammar. Split at rhythm changes and native text interruptions. The 2401 title block is excluded by a document-specific profile.

Build a continuous trace

Only candidate spans become solid. Two-stroke runs need matching pattern evidence at an endpoint of a longer run. Corners remain separate runs. Crossings stay independent and do not become plant junctions. Use semantic JSON with every flattened image.

Attach evidence

The 2401 note identifies double-dot-dash supply boundaries. Electrical-signal labels are legend-based candidates. Other meanings remain unknown until you assign them.
